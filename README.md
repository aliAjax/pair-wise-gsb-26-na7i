# hxwl-12 团体小组排场次

心理咨询机构团体小组的场次登记、排队候补、转正提醒与督导调整单系统。

## 技术栈

React 19 + Vite + TypeScript（严格模式）+ 原生 CSS，数据保存在浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5112
npm test           # 领域规则测试（node:test，12 个用例）
npm run build      # 类型检查 + 生产构建
```

## 业务规则

- **开组登记**：顾问登记小组主题、容量、开组时间与时长。
- **报名排队**：来访者按提交先后报名；有空位直接占正式席位，满员进候补；
  同一人在时段重叠的场次中只能占一个组（正式席位、待确认、候补均算占用）。
- **退出与顺补**：成员退出后记录保留在原场次（标注原身份）；最早候补收到转正提醒，
  24 小时内确认即转正，超时未确认或婉拒则自动顺给下一位候补。
- **督导锁定与调整单**：督导锁定的场次不能直接编辑或取消，顾问须另建带原因的调整单，
  督导批准后变更才生效；原席位、名单（含退出记录）与变更留痕始终可查。
- **本地保存**：所有操作即时写入 localStorage，刷新不丢失；页脚可重置演示数据。

## 模块结构（四块分开实现）

```
src/domain/    领域规则，不依赖 React / 存储 / 页面
  types.ts         数据模型与常量（24h 确认期限）
  sessions.ts      场次资料：登记、容量核算、时段重叠、锁定
  queue.ts         排队规则：报名、退出、提醒、确认、超时顺延
  adjustments.ts   调整单：创建（强制原因）、批准、驳回
src/storage/   本地保存：localStorage 读写，零业务规则
src/state/     种子数据 + React store（串联领域规则与持久化、模拟时钟）
src/ui/        页面与组件（场次列表 / 场次详情 / 通知中心 / 调整单审批）
tests/         领域规则测试
```

## 演示说明

内置三类身份（右上角切换）：来访者、顾问、督导。页脚提供模拟时钟
（快进 1 小时 / 25 小时），可直接演示「转正提醒一天内未确认即顺给下一位」。
种子数据中《焦虑情绪调节小组》已有一条发出 4 小时的转正提醒。

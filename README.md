# 团体小组排场次

心理咨询机构团体小组的场次登记、报名候补与督导锁定调整系统。

## 业务规则

- **开组**：顾问每周开出不同主题的组，登记容量、开组时间与场地。
- **报名**：来访者按提交先后报名；同一人同一时段只能占一个组（与已有席位/候补时段冲突时拒绝）。有剩余容量直接占席，满员进候补。
- **候补转正**：有人退出释放席位时，系统给最早候补发「转正提醒」；**一天（24h）内未确认自动顺给下一位**。候补可主动放弃，立刻顺给下一位。
- **退出留痕**：退出记录留在原场次，历史名单可随时追溯。
- **督导锁定**：锁定组不能直接改名单/容量/时间，只能另建**带原因的调整单**（调容量 / 调时间 / 取消），督导审批后生效；提单时的原席位与名单快照随单保留。

## 分层实现

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 场次资料（领域数据） | `src/types.ts`、`src/domain/sessions.ts`、`src/domain/time.ts` | 数据结构与只读汇总，不依赖 React |
| 排队规则 | `src/domain/queue.ts` | 报名/候补/提醒/顺延/退出/调整单的纯函数 |
| 本地保存 | `src/storage/local.ts` | localStorage 读写，带版本号与坏数据兜底 |
| 页面 | `src/pages/`、`src/components/`、`src/App.tsx` | React 视图，经 `src/state/store.ts` 调用规则并保存 |

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 演示说明

- 首次打开载入 `src/domain/seed.ts` 演示数据：含满员候补场次、可退出触发转正的场次、一张待审批的锁定组调整单。
- 右上角可切换 **顾问 / 前台 / 督导** 身份，权限不同（前台不能开组、不能动锁定组；督导负责锁定与审批）。
- 「+1 小时 / +25 小时」可快进机构时钟，演示一天确认期到期后自动顺给下一位候补。
- 「重置」清空本地数据并恢复演示数据。
